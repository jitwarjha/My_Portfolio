# Jitwar Jha — Personal Portfolio

> Built with React, Vite, and custom modern editorial styling.

## 🚀 Live Preview
Run:
```bash
npm install
npm run dev
```
Or view the production build:
```bash
npm run preview
```

## 🎨 Features
- **Editorial Typography & Layout**: Distinctive serif and sans-serif combination, numbering, asterisk status indicators, and minimalist aesthetic.
- **Cinematic Curtain Transition**: Fullscreen expanding curtain wipe with simulated loader (0% → 100%) when navigating between sections.
- **Motion Reel Hero**: Smooth hardware-accelerated continuous video loop showcasing systems in action.
- **Horizontal Works Gallery**: Grouped by year (2026, 2025, 2024) with interactive modal drawer for system architecture deep dives.
- **Resume Content Integration**: Full integration of KisanSetu (SIH 21st rank), Mess Management System, LeetCode (35+ solved), education at PIET Jaipur, and complete technical skill sets.
- **Mobile Friendly & Responsive**: Optimized touch navigation, responsive layouts for all viewports, and direct contact avenues.
